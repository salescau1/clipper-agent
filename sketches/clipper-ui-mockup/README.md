# Clipper Agent UI Mockup

## Design stance
A polished SaaS-style production studio for turning one YouTube URL into multiple ready-to-post short videos.

## Core UX
- Primary action: paste YouTube URL and run pipeline.
- Secondary action: monitor each stage and open final output.
- Review action: preview generated clips and inspect quality/log/path tabs.

## Key choices
- Layout: persistent sidebar, hero launcher, latest-run progress card, generated-clip list, vertical preview, and diagnostics panel.
- Visual style: dark AI-production dashboard with cyan/purple accents.
- Interaction: run toast, preview toast, output modal, tab switching for logs/quality/paths, hover highlights.
- Content: uses real result from latest test URL and output counts.

## Best for
The main Clipper desktop/web app dashboard where the user wants a good UX without touching the terminal.
